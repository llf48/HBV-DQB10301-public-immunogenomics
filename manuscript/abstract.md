# Abstract

## Title

Public HBV genotype B/C core diversity preserves an HLA-DQB1*03:01-associated
class-II antigen-presentation gap

## Structured Abstract

**Background:** HLA-DQB1*03:01 has recently been associated with increased risk
of hepatitis B virus (HBV)-related hepatocellular carcinoma (HCC), with
reference-sequence analyses suggesting reduced HLA-DQ binding to HBV
nucleocapsid peptides. Whether this predicted presentation gap is robust across
real-world HBV genotype B/C core diversity remains unknown.

**Methods:** We downloaded public HBV complete-genome GenBank records annotated
as genotype B or C and extracted translated core protein sequences. After
excluding recombinant records, abnormal core lengths, missing core CDS, and
non-standard amino-acid sequences, 469 records were retained. Overlapping core
15-mers were collapsed into 5670 unique peptide windows with occurrence counts.
IEDB MHC-II predictions using NetMHCIIpan were run for two DQB1*03:01-containing
HLA-DQ heterodimers (DQA1*05:08/DQB1*03:01 and DQA1*06:01/DQB1*03:01) and one
DQB1*03:02 comparator (DQA1*03:01/DQB1*03:02). Percentile rank <10 was defined
as predicted binding and rank <2 as strong binding.

**Results:** The DQB1*03:02 comparator bound 511 of 5670 unique core 15-mers
(9.01%) and 8077 of 77579 occurrence-weighted windows (10.41%). In contrast,
DQA1*05:08/DQB1*03:01 bound 60 unique peptides (1.06%) and 193 occurrence-
weighted windows (0.25%), while DQA1*06:01/DQB1*03:01 bound 67 unique peptides
(1.18%) and 638 occurrence-weighted windows (0.82%). The DQB1*03:02 comparator
showed higher predicted binding than both DQB1*03:01 pairs in unique peptide
analyses (OR 9.26 and 8.28; both P < 3e-89) and occurrence-weighted analyses
(OR 46.60 and 14.01; both P < 1e-300). The gap was observed within both
genotype B and genotype C occurrence-weighted analyses.

**Conclusions:** Public HBV genotype B/C core diversity preserves a marked
predicted class-II binding gap for DQB1*03:01-containing HLA-DQ heterodimers.
These findings extend the DQB1*03:01-HBV-HCC nucleocapsid axis from a reference-
sequence observation to public viral sequence diversity, while remaining
hypothesis-generating and requiring experimental validation.
